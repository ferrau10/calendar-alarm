# Calendar Alarm

Never miss a meeting again. Connect your Google Calendar, tap the events you care about, and your Android
phone rings a real alarm — labelled with the event name — a few minutes before each one (5 minutes by default,
configurable globally or per event). Alarms follow the meeting if it moves and disappear if it is cancelled.

## Status
Work in progress — see the [issues](https://github.com/ferrau10/calendar-alarm/issues) for the roadmap.

## Building
Requires JDK 17+ and the Android SDK (platform 35).

```bash
./gradlew assembleDebug
```
